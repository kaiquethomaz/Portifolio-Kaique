# Portfólio — Kaique Thomaz

Portfólio pessoal de **Kaique Thomaz**, desenvolvedor de software.

Site estático (HTML, CSS e JavaScript puro, sem build) com foco em
desenvolvimento, automação e produtos B2B.

## Estrutura

```
index.html     # página única
styles.css     # estilos (tema escuro)
script.js      # header sticky, reveal no scroll, carrossel
assets/        # imagens (foto, prints, favicon, og-image)
```

## Rodar localmente

Basta abrir o `index.html` no navegador, ou servir a pasta:

```bash
python -m http.server 8777
```

Depois acesse `http://localhost:8777`.

## Deploy

Publicado via [Netlify](https://www.netlify.com/) — cada push na branch
principal atualiza o site automaticamente.
